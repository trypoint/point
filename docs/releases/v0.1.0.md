# Point Framework v0.1.0 — release notes draft

**Status: draft pending final maintainer approval.** Publication date intentionally omitted.

## Overview

Point is a lightweight PSR-compatible PHP microframework. This release candidate sets the runtime version to `0.1.0` and targets PHP `>=8.4.27`. CI validates PHP 8.4.27, PHP 8.4, and PHP 8.5 on Ubuntu; PHP 8.4 and PHP 8.5 on Windows; and an Ubuntu Nginx/PHP-FPM fixture. These CI fixtures do not certify a production server or proxy topology.

Install after publication with:

```bash
composer require trypoint/point:^0.1
```

The package includes HttpSoft as its PSR-7/PSR-17 fallback. Optional complete providers include Nyholm, Laminas Diactoros, and Guzzle PSR-7. Runtime dependencies are listed in the package's `composer.json` and remain unchanged from RC.1.

## Changes

- XML exception responses preserve dynamic titles containing XML markup characters and Unicode while producing valid XML.
- XML request parsing restores the previous libxml error mode on success and failure.
- Release documentation clarifies supported PHP versions, API compatibility proposal, and deployment trust boundaries.

## Compatibility and security

The proposed API freeze is awaiting maintainer approval. Until that decision is recorded, this draft does not claim that provisional APIs have been frozen. See the [API freeze approval record](../architecture/STABLE-0.1.0-API-FREEZE.md) and [security/readiness gates](../architecture/STABLE-0.1.0-RELEASE-READINESS.md).

Set request-body limits at a trusted ingress before enabling JSON, form, or XML parsing. Validate Host and forwarded headers at a trusted proxy and restrict direct backend access. Production deployment configurations and the actual production TLS/proxy topology have not been independently validated.
